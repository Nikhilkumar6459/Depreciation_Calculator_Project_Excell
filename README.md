# Depreciation Calculator: Straight-Line vs. Diminishing Balance

## Project Description

This project focuses on calculating and comparing depreciation using two commonly used accounting methods: **Straight-Line Method** and **Diminishing Balance Method**. The project uses Microsoft Excel to calculate annual depreciation, total depreciation, and closing book value over an asset's useful life.

The Excel-based calculator demonstrates how depreciation expenses vary between the two methods and how each method affects an asset's book value over time. A comparative project report is also included to explain the calculations, assumptions, results, and key findings.

## Project Objectives

- Calculate annual depreciation using the Straight-Line Method.
- Calculate depreciation using the Diminishing Balance Method.
- Develop a 10-year depreciation schedule.
- Compare annual depreciation expenses and closing book values.
- Understand how different depreciation methods affect asset valuation over time.

## Depreciation Methods

**1. Straight-Line Method**

Depreciation is calculated equally over the useful life of the asset.

Formula:  
`Annual Depreciation = (Asset Cost - Scrap Value) / Useful Life`

- Annual depreciation: ₹45,000
- Total depreciation: ₹4,50,000
- Closing book value: ₹50,000

**2. Diminishing Balance Method**

Depreciation is calculated annually on the opening book value of the asset, resulting in a higher depreciation expense in the earlier years and a declining expense in subsequent years.

- Calculated depreciation rate: 20.57%
- Depreciation schedule: 10 years
- Closing book value at the end of Year 10: ₹50,000
